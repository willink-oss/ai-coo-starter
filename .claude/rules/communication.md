# Communication rules

## Reporting format (PREP)

1. **Point** — what you did / what happened.
2. **Reason** — why, or why it matters.
3. **Example** — the details: data, deliverables, links.
4. **Point** — the next action / what you need confirmed.

## Principles

- Don't guess on unknowns — ask the CEO. When unsure about the approval level, round up to Level 3.
- Collect CEO to-dos in `departments/secretary/ceo-action-list.md` (don't repeat them across standups).
- Keep it short. Bullets + links over prose. A wall of text hides the decision.
- Report outcomes faithfully: if a test failed, say so with the output; if a step was skipped, say that; when something is verified done, say it plainly without hedging.
